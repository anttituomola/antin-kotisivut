# Blogiteksti-ideapankki (esimerkkipohja)

Tämä tiedosto on **julkinen malli** repossa. Omat ideat eivät kuulu versionhallintaan.

1. Kopioi tämä tiedosto nimellä `docs/blog-ideapankki.local.md` (gitignore).
2. Täytä ideat paikallisesti. Älä commitoi `*.local.md`-tiedostoa.

Julkaistut tekstit: `src/content/blog/` (MDX, `fi-` / `en-` etuliitteet). Uuden postauksen luontiin voi käyttää arkistoitua mallia `archived/blog-and-timeline/createPost.js`.

## Uuden idean pohja

Kopioi alla oleva lohko **Ideat**-osion alle ja täytä kentät. Pidä status ajan tasalla.

```markdown
### [Otsikko]

- **Status:** idea | drafting | published
- **Pitch:** yksi–kaksi lausetta, miksi tästä kannattaa kirjoittaa
- **Kieli:** fi | en | molemmat
- **Tagit (ehdollisesti):** …
- **Muistiinpanot / koukut:** bulletit, case-esimerkit, linkit
- **Julkaistu:** (jos published) polku tai slug
```
